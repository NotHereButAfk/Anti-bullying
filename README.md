# After the Bell — Anti-bullying

A browser-based branching story prototype about school bullying, friendships, and decisions.

## Playing
Open `index.html` in a browser. You can also use any static web server. No dependencies or login are required.

## Currently implemented
- Eight branching decision points, with four choices at each.
- Confidence, stress, friendship, school climate, and trusted support react to decisions.
- Prior decisions alter later dialogue and several endings.
- Local save/load, restart, and choice shortcuts (keys 1–4).
- Mobile-friendly, accessible buttons and reduced-motion support.

## Roadmap
The original vision is a large narrative with numerous distinct routes. This is an initial prototype, **not** ten million distinct authored stories. There are up to 65,536 choice sequences (4^8) in the existing eight decision points, many sharing scenes and outcomes.

Next: separate scene data and engine, conditional branching scene graph, more character perspectives (targeted student, bystander, and someone trying to change harmful behavior), a journal, more locations, additional chapters, and consistency tests.

## Editorial principles
Bullying is never presented as the target's fault. Help-seeking is legitimate, confronting someone alone is not always safe, and repairing trust may take time. This is fictional gameplay, not professional advice.
